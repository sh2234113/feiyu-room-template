# 3D 模型（作者提供）

本模板附带作者提供的**优化版展示模型**和**原始工程模型**：

```text
da-feiyu.opt.glb   6.7 MB，约 24 万三角面，47 个部件；页面实际加载的文件
da-feiyu.glb      58.9 MB，约 140 万三角面；原始工程备份，页面不加载
```

两个文件都随模板分发。仓库因此约 85 MB，GitHub 会对 50 MB 以上文件给出警告，但 58.9 MB 仍低于 100 MB 硬上限。

## 模型约定

- 单位：米；Y 轴向上；原点在脚底；正面朝 +Z；
- 运行时高度约 1.42 m；
- 没有骨骼/动画；站立、坐、躺用根节点变换，移动用顶点着色器摆动下半身；
- 想换模型：保持“脚底在 y=0、正面朝 +Z”，并把 `model-actor.js` 的 `MODEL_URL` 指向你的文件。
